# JOELAKAYA PMU V2

Le fichier à mettre en ligne est **index.html**.

IMPORTANT : si GitHub affiche seulement le titre `joelakaya_PMU`, vous êtes probablement en train d'afficher le README.md ou la page du dépôt, et non la page GitHub Pages.

## GitHub Pages
1. Dans le dépôt, ouvrez `index.html` et vérifiez qu'il contient tout le code HTML.
2. Allez dans Settings → Pages.
3. Source : Deploy from a branch.
4. Branch : main ; dossier : /(root).
5. Save.
6. Ouvrez ensuite l'adresse GitHub Pages fournie par GitHub, pas l'URL de prévisualisation du fichier README.

La V2 est autonome : aucun framework externe n'est nécessaire.
