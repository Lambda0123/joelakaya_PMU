# JOELAKAYA PMU V9

Cette version affiche séparément les sélections de plusieurs sources, calcule une convergence et produit des propositions par type de jeu.

## Important
- Les sites de pronostics externes ne sont pas des sources « officielles PMU ».
- Une convergence de pronostics ne permet pas de garantir l'arrivée.
- La promesse de 99,99 % de proximité n'est pas réaliste et n'est pas affichée comme garantie.
- GitHub Pages est statique. Pour actualiser les données, un GitHub Action est fourni. Il lit uniquement des pages publiques et peut nécessiter une adaptation si leur structure change.
